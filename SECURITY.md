# Security policy

*Deutsche Fassung weiter unten.*

## Supported versions

Only the newest release (alpha or beta) gets security fixes. Please update before reporting.

Security fixes are released as versions with a "Security" part in the changelog. On the Raspberry Pi they are
installed automatically (Options › System › Updates, on by default); the Windows and Mac app show a notification.
Security updates of the Python packages (found by Dependabot) are tested, released and rolled out the same way.

## Reporting a vulnerability

Please **do not** report security issues in public issues or discussions.

Use GitHub's private reporting instead:
[Report a vulnerability](https://github.com/pixxelhoff/pixxelspool/security/advisories/new)
(tab "Security" › "Report a vulnerability"). Only you and the maintainer can see the report.

Please describe the problem, the affected version and platform (Raspberry Pi, Windows app, Mac app) and how to
reproduce it. Do not include your own tokens, passwords, access codes or IP addresses.

PixxelSpool is a hobby project, so answers may take a few days. Once a fix is released, the report can be
published with credit to you, if you like.

# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitskorrekturen gibt es nur für die neueste Version (Alpha oder Beta). Bitte vor einer Meldung aktualisieren.

Sicherheitskorrekturen erscheinen als Versionen mit einem Abschnitt „Security“ im Changelog. Auf dem Raspberry Pi
werden sie automatisch installiert (Optionen › Über PixxelSpool › Updates, ab Werk an); die Windows- und Mac-App
zeigen eine Benachrichtigung. Sicherheitsupdates der Python-Pakete (von Dependabot gefunden) werden genauso
getestet, veröffentlicht und verteilt.

## Sicherheitslücke melden

Bitte Sicherheitslücken **nicht** öffentlich in Issues oder Discussions melden.

Nutze stattdessen die vertrauliche Meldung von GitHub:
[Report a vulnerability](https://github.com/pixxelhoff/pixxelspool/security/advisories/new)
(Reiter „Security“ › „Report a vulnerability“). Die Meldung sehen nur du und der Betreuer des Projekts.

Beschreib bitte das Problem, die betroffene Version und Plattform (Raspberry Pi, Windows-App, Mac-App) und wie man
es nachstellen kann. Gib keine eigenen Tokens, Passwörter, Zugangscodes oder IP-Adressen an.

PixxelSpool ist ein Hobbyprojekt, eine Antwort kann daher ein paar Tage dauern. Sobald eine Korrektur erschienen
ist, kann die Meldung veröffentlicht werden, auf Wunsch mit deinem Namen.

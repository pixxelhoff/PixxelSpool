        Storage and alerts

        Set up storage

        A storage can be a cabinet, a shelf unit, a rod on the wall or anything similar. Its name is up to you. PixxelSpool tells apart the active storage, where every spool has a fixed slot, and the reserve for spare spools, which has no fixed slots or order.

        When you apply, slot codes are updated and all spools move along. A backup is made first. Slots that still hold a spool can't be removed.

        Shopping and prices

        Other brands

        Add filament from other makers, e.g. Sunlu, eSun or Polymaker: a line with material, weight and price, plus its colors. They then appear under “Add spool manually”. With an NFC sticker you find them by placing them on the reader, just like Bambu spools.

        Standard price per line

        What one spool of a line normally costs. It is suggested when you add a spool by hand and is used for value and print costs wherever a spool has no price of its own. Bambu Lab lines start with the prices of the Bambu Lab shop; change them to what you usually pay. Next to each line: what you actually paid on average.

        Prices per delivery

        What you paid per spool for a delivery. Applies to all spools of the line stored on that day.

        Shopping list

        Lines you want to have complete. Missing colors from them go on the shopping list.

        Printer and devices

        Printer

        PixxelSpool connects to your printer locally on your home network and reads the AMS, remaining amounts and the print job – no cloud, no Bambu account. For now PixxelSpool only switches the printer light; more controls are planned.

          Name
          IP address
          Serial number
          Access code

          You can find these values on the printer’s display: Settings › Network (IP address, access code) and Settings › Device (serial number). The access code is only stored locally in PixxelSpool.

          Camera image

          Shows the camera image in the printer card. 1 fps: hardly any load. 5 fps: needs about one CPU core. Max: every frame the printer sends (up to 30 per second), needs much more computing power. The camera only runs while someone is looking at the card.

          Experimental: the camera image has only been tested with a few printers so far and may not work with yours.

          NFC reader

          Pause after a scan seconds
          Reader type

          “Automatic” finds a USB reader and a PN532 by itself. Only choose a type if your reader is not detected.

          Which readers work?

          You need a 13.56 MHz NFC reader that can read MIFARE Classic. Not suitable: readers that act as a keyboard and only “type” a number, and 125 kHz readers.

          Plug & play

          • ACS ACR122U tested
          • ACS ACR1252U tested
          • PN532 module with USB-C tested
            Setup

            Set both switches to HSU or UART (usually both OFF), then plug it in via USB. PixxelSpool finds the port by itself.

          Other (on the Raspberry Pi)

          • Waveshare PN532 NFC HAT untested
            Port

            Set the jumpers to I2C (I0 = H, I1 = L) and plug it onto the Pi.

          • PN532 NFC Modul V3 untested
            Wiring

            Switches to I2C (1 = ON, 2 = OFF). VCC → 3.3 V (pin 1), GND → pin 6, SDA → pin 3, SCL → pin 5. The install script turns on I2C.

          Tried another reader? Put a spool on it: if PixxelSpool reacts, it works. Let us know on GitHub know and it goes on the list.

          No reader yet? Your AMS can read the spools too.

          Once your printer is connected, PixxelSpool detects a Bambu Lab spool you put into the AMS and asks whether to add it to storage. To put it away, simply take it out again: PixxelSpool shows you its slot.

          We still recommend a separate NFC reader: it's faster, you don't have to unpack spools, and spools from other brands with NFC stickers only work with a reader.

          Backup

          Downloads a ZIP file with the database (all spools, history, usage) and all settings including the storage layout. PixxelSpool also makes a backup automatically every night at 3:30.

          Network backup

          Also stores the nightly backup on a network share. Credentials are only stored locally in PixxelSpool.

          Password

          Optional: PixxelSpool only opens after entering a password. Useful if others in your network shouldn't change anything. Each device stays signed in for 30 days. Scanning at the reader keeps working without a password.

          Remote access

          Open PixxelSpool on the go, securely via Tailscale: only your own devices get in, and nothing has to be opened on the router. Install the Tailscale app on your phone once and sign in with the same account.

          …

          Updates

          New versions come straight from GitHub; PixxelSpool only installs a download whose checksum matches. Before every update it backs up the database and the current version; your data stays unchanged.

          …

          Check for updates daily
          Offer pre-releases Beta: tested, shortly before the final version. Alpha: also the newest test versions. Both may contain bugs.
          Install security updates automatically Checked daily, only versions marked as security updates. The database is backed up first; if the new version does not start, PixxelSpool goes back to the old one by itself.

          Log

          PixxelSpool messages for troubleshooting, newest first. Access codes, tokens and passwords are redacted, in the export too.

          Detailed log For troubleshooting: also records printer data, reader scans and every change. Switch it off again afterwards.
          ExportReport a bug

          Report a bug: opens a form on GitHub with version, platform and printer already filled in. Attach the exported log if it helps.

          Reset PixxelSpool

          Starts PixxelSpool again like a new installation: storage, history, settings, printer, Home Assistant, password and push are deleted and the setup assistant opens. Download a backup first if you might want your data back.

              Load a picture and tap the spots whose color you are looking for. For each point PixxelSpool shows the closest Bambu filaments.
